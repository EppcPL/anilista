Połączenie z GitHubem
  1. Otwórz github.com → nowy token (fine-grained).
  2. Nazwa dowolna, np. „anilista”. Przy Repository access wybierz Only select repositories → anilista.
  3. Rozwiń Repository permissions (nie „Account permissions”!) i przy Contents wybierz Read and write. Ta lista pojawia się dopiero po wybraniu repo w poprzednim kroku.
  4. Kliknij Generate token, skopiuj go i wklej poniżej.

Token zapisuje się tylko w tej przeglądarce i nie trafia do repo. Ma dostęp wyłącznie do repo anilista.
